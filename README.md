# Trivia Quiz 
A terminal-based 5-question trivia quiz.

---

## 1. Description
- Language: Python
- Input: Text / number answers
- Output: Correct / Wrong feedback + final score
- Questions: 5 fixed questions
- Max Score: 5 points

---

## 2. How It Works
1. User is asked if they want to play (must type "yes" to continue)
2. 5 questions are asked one by one
3. Each correct answer adds 1 point
4. Wrong answers print "Wrong answer" with no penalty
5. Final score is shown at the end

---

## 3. Input / Output
| Question | Correct Answer | Wrong Example |
|---|---|---|
| Capital of India? | delhi | mumbai → "Wrong answer" |
| Continents on Earth? | 7 | 5 → "Wrong answer" |
| Closest planet to Sun? | mercury | venus → "Wrong answer" |
| Square root of 64? | 8 | 6 → "Wrong answer" |
| CPU stands for? | central processing unit | processor → "Wrong answer" |
